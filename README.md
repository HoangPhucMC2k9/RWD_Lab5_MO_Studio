# MƠ Studio | RWD Lab 5

Website boutique thời trang tối giản, dự án mới độc lập cho bài thực hành RWD Lab 5.

## Pages
- Trang chủ: danh mục 8 sản phẩm, tìm kiếm, lọc theo danh mục.
- Về MƠ: câu chuyện và triết lý thương hiệu.
- Liên hệ: form kiểm tra dữ liệu và lưu bản demo bằng localStorage.

## Kỹ thuật
HTML5, CSS3, Bootstrap 5, CSS Grid, Flexbox, Media Queries, JavaScript ES6, localStorage, SEO cơ bản.

## Chạy thử
Mở `index.html` bằng VS Code Live Server. Bootstrap và ảnh Pexels được tải qua CDN nên cần internet.

## GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Hình ảnh
10 ảnh thời trang JPG thật đã được tải về, nén bằng Pillow và lưu trực tiếp trong `assets/img/optimized/`. Nguồn ảnh, kích thước và dung lượng nằm trong `assets/img/optimized/IMAGE_SOURCES.txt`. Ảnh sử dụng theo Pexels License.

## Lưu ý
Form liên hệ chỉ lưu dữ liệu demo trên trình duyệt, không gửi tới máy chủ. Chạy Lighthouse và bổ sung ảnh minh chứng thực tế trước khi nộp.
